About Skill Swap Platform

Skill Swap Platform is a web application where students can share their skills, discover new skills, and connect with others through skill exchange.

Our Features

  • 🔍 Search Skills
  • ➕ Add New Skills
  • ⭐ Favorite Skills
  • 📝 Edit Skills
  • 🗑️ Delete Skills
  • 📂 Category Filter
  • 🌙 Dark Mode
  • 📊 Total Skills Counter

Our Mission

Our mission is to help students learn from each other by sharing knowledge and building a strong learning community.
